Privacy Notice & Technical Transparency

Full architectural disclosure of what PermissionLens reads, what stays local, and how security works.

🔒

100% Local-First Operation

Permission queries execute strictly in your local browser sandbox via standard navigator.permissions. The extension never scrapes passwords, cookies, authentication tokens, form inputs, or page contents.

🔍

Honest Technical Limitations

Modern browsers only expose permissions that support the W3C Permissions API. If an API does not support programmatic querying, we display "Not available through this browser API" rather than inventing data.

☁️

Supabase Cloud Integration

The backend database provides pre-seeded educational permission metadata and sample profiles via public publishable keys with Row-Level Security (RLS). Complete offline fallback is built-in.

⚙️

How to Control & Revoke

To change or revoke permissions for any website, open Chrome Site Settings (chrome://settings/content) or click the lock icon next to the address bar.
